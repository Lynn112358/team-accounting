# Team Accounting

一个纯前端的 AA 制团队记账应用，支持多币种、多人分账和自动结算。

## 功能

- **多项目管理** — 创建和管理多个独立的记账项目
- **成员管理** — 每个项目可添加/移除成员
- **多币种支持** — 内置 12 种货币汇率，支持自定义汇率
- **灵活分账** — 支持均分和自定义金额两种分摊方式
- **自动结算** — 自动计算成员间的债务关系，生成最优结算方案
- **统计概览** — 总支出、分类占比、成员排名一目了然
- **本地存储** — 数据保存在浏览器 localStorage，无需后端

## 技术栈

- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router v6

## 快速开始

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 预览构建结果
pnpm preview
```

## 项目结构

```
src/
├── components/     # 通用组件
├── context/        # 全局状态 (useReducer + Context)
├── pages/          # 页面组件
├── types/          # TypeScript 类型定义
└── utils/          # 工具函数 (货币转换、结算算法)
```

## 使用方式

1. 首页创建一个新项目，设置基准货币
2. 在项目设置中添加成员和自定义分类
3. 添加支出记录，选择付款人和参与人
4. 在结算页面查看谁该给谁转多少钱
5. 统计页面查看支出分布和排名
